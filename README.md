# 📊 Santander - Excel com IA e Claude

Repositório de projetos e atividades práticas desenvolvidos no bootcamp **Santander - Excel com IA e Claude**, promovido pela **DIO (Digital Innovation One)** em parceria com o **Santander**.

---

## 🎯 Objetivo

Consolidar o uso de planilhas inteligentes, tratamento de dados, automação e inteligência artificial aplicada à análise de dados e tomada de decisões corporativas.

---

## 🚀 Projetos no Repositório

### 1. 🎮 [Xbox Game Pass Subscriptions Dashboard](./dashboard%20xbox.xlsx)
- **Tecnologias:** Microsoft Excel, Tabelas Dinâmicas, IA Generativa (Claude/ChatGPT).
- **Descrição:** Painel financeiro e operacional focado na análise de receitas, distribuição de planos (Ultimate, Core, Standard) e engajamento no ecossistema Xbox.
- **Destaques:** Tratamento de dados brutos, criação de KPIs de receita e uso de IA para otimização de formulas e visual.

### 2. 🏎️ [Porsche Sales Intelligence](./index.html)
- **Tecnologias:** HTML5, CSS3, JavaScript (ES6+), Chart.js.
- **Descrição:** Painel de inteligência comercial focado no mercado de veículos de luxo (EUA).
- **Destaques:** Saneamento de dados, filtros dinâmicos em tempo real, leaderboard de modelos mais vendidos e gráficos de evolução temporal.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Análise & Modelagem:** Microsoft Excel (Fórmulas Avançadas, Power Query, Tabelas Dinâmicas)
- **Visualização de Dados:** Chart.js, Dashboards Interativos
- **Inteligência Artificial:** Claude AI, ChatGPT (Prompt Engineering e Automação de Análises)
- **Desenvolvimento Web:** HTML5, CSS Custom Properties, JavaScript Vanilla
