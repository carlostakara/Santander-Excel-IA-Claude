# Santander - Excel com IA e Claude

Este repositório reúne os projetos desenvolvidos durante a trilha **Santander - Excel com IA e Claude**, promovida pela DIO em parceria com o Santander.

A proposta do programa é capacitar profissionais desde os fundamentos do Excel até a aplicação de Inteligência Artificial em análise de dados, automação de processos e construção de dashboards interativos. O conteúdo combina Excel, Power Query, IA Generativa e boas práticas de análise de dados para resolver problemas reais de negócio. :contentReference[oaicite:0]{index=0}

---

## Objetivos de Aprendizagem

- Dominar os fundamentos e recursos avançados do Excel;
- Aplicar fórmulas e funções para análise de dados;
- Utilizar Tabelas Dinâmicas e Dashboards;
- Automatizar processos utilizando Inteligência Artificial;
- Desenvolver projetos práticos voltados para o mercado;
- Construir um portfólio de projetos com Excel e IA.

---

## Projetos Desenvolvidos

### 📊 Organizador de Imposto de Renda

Ferramenta desenvolvida em Excel para auxiliar na organização de informações utilizadas na declaração de Imposto de Renda, promovendo maior controle e praticidade na gestão dos dados financeiros.

### 🤖 Excel + Claude (IA)

Projeto voltado para a utilização de Inteligência Artificial como apoio à análise e tratamento de dados, explorando o uso do Claude como ferramenta complementar para geração de insights, automação e produtividade.
